Computational scientist working at the intersection of machine learning and dynamical systems.

Research includes physics-informed and Hamiltonian neural networks for chaotic dynamics ([OrderChaosHNN](https://github.com/anshu957/OrderChaosHNN)), reservoir computing for chaotic system prediction ([Chaos_ReservoirComputing](https://github.com/anshu957/Chaos_ReservoirComputing)), and weak-winner phase synchronization in coupled oscillators ([WeakWinner](https://github.com/anshu957/WeakWinner)).

Current focus: neural ODEs for single-cell fate prediction and trajectory inference in scRNA-seq. Also building unsupervised pipelines for animal behavior quantification ([JABS-tutorial](https://github.com/anshu957/JABS-tutorial)).
